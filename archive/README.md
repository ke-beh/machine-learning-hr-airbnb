# Original coursework source

These are historical notebooks from the October 2023 semester, with Assignment 2
deadlines in January and February 2024. They are retained to show the original
analysis and experiments. The 2026 revision addresses the evaluation issues
documented in the technical review.

**The original scores are affected by data leakage.** See
[the technical review](../docs/REVIEW.md) and [current workflow](../README.md).

Original source cells are preserved. Saved outputs, execution counts and
environment metadata were removed; a review notice was added. Original file
hashes and cell counts are recorded in `source_manifest.json`. Original report,
assignment brief, data and unmodified notebooks are kept locally.

These notebooks contain the original leakage issues, large searches, package
installation cells and older dependency assumptions. To run the revised benchmark,
use `src.evaluate` as described in the main README.
